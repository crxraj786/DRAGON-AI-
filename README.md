# DRAGON AI

A mobile-first, free-first AI assistant frontend built with React and Vite.

## Current status

This repository currently provides the **frontend/demo foundation**. Demo replies are explicitly labelled and are not generated by a real model. Provider selection is a preference only until a secure server-side integration is configured.

### Implemented
- Responsive chat interface for mobile and desktop
- Hindi/English UI preference
- Local conversation history and settings
- JSON export and destructive-action confirmation
- Offline/online indicator
- Defensive client-side storage and input validation utilities
- Unit tests for core utilities

### Not yet implemented
- Real model calls and server-side secret management
- Authentication, authorization, cloud-synced history and workspace roles
- File processing, web research, image/audio/video tools, code sandbox, agents and automation
- Production monitoring and full end-to-end/accessibility testing
- Android APK build and installation validation

## Requirements

- Node.js 20 or newer recommended
- npm

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run build
```

## Deployment

The Vercel production deployment is configured to build this repository. GitHub Pages requires Pages deployment permissions/settings to be enabled separately.

## Security notes

Never place provider API keys in browser code or Vite `VITE_*` variables. Real AI integration must call a server-side endpoint that validates input, applies rate limits, handles provider errors and keeps secrets in server-only environment variables. Do not put real secrets in commits or client bundles.

## Project principles

- Preserve existing user data and existing project work.
- Clearly distinguish simulated/demo behavior from real provider-backed behavior.
- Prefer modular code, deterministic tests, accessible controls and explicit error states.
- Only claim capabilities that are implemented and verified.
